# Rhinestone Lab

[Open Rhinestone Lab](https://rhinestonelab.com/)

Rhinestone Lab is an English-language browser tool for making rhinestone templates from text, artwork and portraits. Set dimensions in millimeters, compare image treatments before applying them, edit individual stones, and export production files.

This repository contains public product documentation only. It does not contain the application source code, commercial template code, private project files, or customer data.

## What you can do

- Generate text layouts with bundled outline fonts, image layouts, and portrait layouts.
- Use multiple stone colors and sizes; inspect hole spacing and collisions.
- Edit, save local projects, and download editable project backups.
- Export SVG, DXF, PDF guides, PNG previews, material lists, and ZIP packages.
- Compare silhouette, dark-detail, and limited-color treatments before applying a new layout.
- Resize an imported rhinestone SVG while keeping hole diameters fixed.
- Preview a design on a T-shirt. The garment preview is not a cutting file.

## Try it

1. [Open the studio](https://rhinestonelab.com/), choose text, artwork, or portrait, and set the physical dimensions.
2. Create the layout, inspect the preview, and apply it when ready.
3. Run the design checks and inspect the hole diameter and spacing.
4. Export your files and an editable project backup.
5. Verify scale in your cutting software and make a calibration test before production.

The public preview accepts no real payment. Advanced multi-color or multi-size packages use simulated credits with no cash value. A recovery key restores sandbox commercial records; it does not restore designs deleted from your browser.

## Verification limits

The documented software tests cover digital geometry, export structure, editing, local recovery, and the simulated ledger. Actual import in Cricut Design Space and Silhouette Studio, specific cutting machines, materials, cutting, and transfer remain unverified. Portrait recognition depends on the source and settings and is not guaranteed.

Photos and design processing stay in your browser. The hosted sandbox stores only simulation account/order/grant records and hashed recovery/session credentials. Download backups before clearing browser storage. Do not post private recovery keys, personal photos, or complete private projects in public issues.
